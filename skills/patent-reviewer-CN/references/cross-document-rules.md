# 跨文件一致性规则（CN v2）

跨文件核对是 41 个维度的证据来源之一，不能自行生成整体结论。所有输入、规则、工具和原始报告使用 SHA-256 绑定；任一绑定对象变化均使依赖它的语义输入和专项报告失效。

| 稳定规则 ID | 比较对象 | 最低要求 |
|---|---|---|
| `CN-CROSS-TITLE-001` | 请求书、说明书、摘要 | 名称一致；仅空白与末尾标点可忽略。 |
| `CN-CROSS-TERM-001` | 权利要求、说明书、附图 | 记录术语、部件、步骤和标记的原文位置；同义关系不得静默假定。 |
| `CN-CROSS-SUPPORT-001` | 权利要求、说明书 | 逐特征和组合关系的证据矩阵，不以文字命中代替支持判断。 |
| `CN-CROSS-FIGURE-001` | 附图、附图说明、实施方式 | 核对图号、标记和技术关系；仅图片内容保留未验证。 |
| `CN-CROSS-ABSTRACT-001` | 摘要、完整申请 | 摘要不得扩大或改变技术方案，也不得作为修改依据。 |
| `CN-CROSS-AMEND-001` | 原始申请、修改稿 | 每项变化绑定原始位置；支持矩阵不能替代修改超范围审查。 |
| `CN-CROSS-SEARCH-001` | 权利要求、检索证据 | 权利要求变化后旧检索证据失效；v1 manifest 仍不构成三性结论。 |

原始 finding/gap 的守恒按 v2 JSON 的 `finding_conservation` 执行。工具或规范异常不能被写成中国法律 finding。
